Использован Xcode 27.0 (27A266a). Команды воспроизведения находятся в [tests/README.md](../tests/README.md). Снимки README сделаны с демоданными в памяти.

UI-прогон покрывает выполнение задач и прогресс, фильтры, аналитику и подробности дня, высоту заголовков, настройки, расписание, категорию, заметки и подзадачи, подтверждение выхода без фактического выхода, ввод в два шага, повторную клавиатуру, стекло и нижнюю границу списка, удаление и отмену, обновление свайпом и отмену вызывающей задачи синхронизации.

Проверки моделей используют отдельную временную базу. Проверяются повторное открытие файла, связи категорий, подзадачи, выполнение и отмена выполнения, фильтры, расписание, каскадное удаление подзадач и сохранность задач при удалении категории. Пользовательские хранилища не меняются.

## Границы проверки

- UI-тесты работают в симуляторе; полноценного автоматического UI-прогона macOS и физического iPhone не было.
- Тесты синхронизации используют тестовый транспорт. Обмен между реальными аккаунтами Supabase не проверялся.
- Планировщик уведомлений проверен автоматически; фактическая доставка уведомлений системой в фоне не проверялась.
- Runtime-проверки выполнены на iOS 26.3. Вариант интерфейса для iOS 18–25 компилируется, но отдельно на этих системах не запускался.

## Очистка

Удалены старый footer-контроллер и передача нижней панели через AnyView, лишняя логика фокуса прежнего поля, неиспользуемые ошибки синхронизации и пустые заголовки. Стеклянные поверхности используют общий модификатор. Info.plist связан с настройками версии проекта. Локальные видео, промежуточные дизайн-итерации и результаты Xcode исключены из Git, но сохранены на компьютере.
